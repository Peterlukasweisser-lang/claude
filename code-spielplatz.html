🎮 Code-Spielplatz

Hier kannst du deinen eigenen Code ausprobieren.

So geht es

  1. Kopiere deinen Code.
  2. Tippe auf „Einfügen“.
  3. Tippe auf „Start“.

Meine Sammlung

Deine Sammlung bleibt nur auf diesem Gerät.

    Noch nichts gespeichert.

    Für Lehrkräfte

    Der eingefügte Code läuft abgeschottet in einem eigenen Rahmen. Er kann die Sammlung auf diesem Gerät nicht lesen. Diese Seite selbst lädt nichts aus dem Internet und sendet keine Daten.
