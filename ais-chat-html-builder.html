    4 · Als HTML-Datei exportieren

    Speichert den aktuellen Code als eigenständige Datei. Sie läuft ohne diese Seite in jedem Browser.

    Einstellungen und Hinweise

    Der Code läuft in einem abgeschotteten Rahmen und kann die Projekte auf diesem Gerät nicht lesen. Der Builder selbst lädt nichts aus dem Internet und sendet keine Daten. Der exportierte Code läuft außerhalb dieser Abschottung. Fremden Code vor dem Weitergeben prüfen.

    Tipp für den Chat: „Erstelle alles in einer einzigen HTML-Datei, ohne externe Links, Schriften oder Bibliotheken.“
